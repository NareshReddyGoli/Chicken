# 🍗 RK FARMS – Real-Time Poultry Platform

A premium, fast, and real-time ordering platform for fresh chicken and eggs. Designed for speed, ease of use, and professional service management.

---

## 🌟 Key Features

### 🛒 Customer Shop
- **Zero-Authentication**: Customers can order immediately without creating an account.
- **Live Order Tracking**: Orders update in real-time as the team prepares and delivers them.
- **5-Star Rating System**: Automated feedback loop where customers can rate their experience after delivery.
- **Signature UI**: Premium glassmorphism and smooth animations for a high-end shopping feel.

### 👨‍🍳 Worker Station
- **Live Feed**: All incoming orders appear instantly with customer details and locations.
- **One-Click Delivery**: Mark orders as "Prepared" to notify the customer and trigger the rating system.
- **WhatsApp Integration**: Automatically generate receipts and delivery updates with direct links.

### 👑 Admin Dashboard
- **Revenue Control**: Real-time stats on total orders, paid status, and daily earnings.
- **Product Management**: Full control over the catalog (Add, Edit, Delete products).
- **Dynamic Branding**: Upload and sync the **Store Logo** and **Founder/Owner Photos** across all pages instantly.
- **Role-Based Access**: Secure login for staff without complex backend overhead.

---

## 🛠️ Technology Stack

- **Frontend**: Vanilla HTML5, CSS3 (Advanced Glassmorphism & Animations), and JavaScript (ES6+).
- **Real-Time Database**: **Firebase Firestore** for instant synchronization between customers, workers, and admins.
- **Design System**: "Outfit" typography and Material Symbols for a modern, sleek interface.
- **Communications**: WhatsApp Cloud API (Quick-links) for automated customer receipts.

---

## 🚀 Getting Started

1. **Clone the Project**:
   ```bash
   git clone [repository-url]
   ```

2. **Initialize Firebase**:
   Configure your Firestore project in `js/firebase-config.js`.

3. **Serve Locally**:
   Run a local server to view the platform:
   ```bash
   python -m http.server 8080
   ```

4. **Access Portals**:
   - Customer: `customer.html`
   - Admin: `admin.html`
   - Worker: `worker.html`
